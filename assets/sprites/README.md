# 桌面 Sprite 资产

当前工业风资源位于`industrial/`，由 [desktop-sprites.yaml](../config/desktop-sprites.yaml) 显式引用。运行前验证路径与文件大小，Godot首次加载时验证可解码性和像素上限，生成共享纹理和mipmap。运行游戏不需要图片生成服务、Pillow或额外素材下载。

## 分层与几何

| 文件 | 用途与方向 |
| --- | --- |
| `tracked_base.png` | 绿色履带底盘；正俯视，前方为图片右侧 |
| `omni_hull.png` | 蓝色全向车壳/甲板/支架，不包含轮子 |
| `omni_wheel.png` | 单个普通全向轮；横轴对应主滚动方向，不是麦克纳姆轮组 |
| `turret.png` | 中心旋转的炮台盖；灰度金属，按模型配色调制 |
| `barrel.png` | 独立炮管，左端连接炮台，右端为炮口 |
| `armor.png` | 长条装甲壳；安装方向与位置由模型派生 |
| `target.png` | 4:3圆角/倒角靶板，米白底、红色同心圆与深色十字 |
| `forward_marker.svg` | 独立车头标记，简单矢量图标 |
| `projectile.svg` | 金属弹丸图标，简单矢量图标 |

PNG保留透明通道。加载时通过AtlasTexture使用YAML的region_px美术裁切框，不改写原图；避免近乎透明的边缘杂点扩大范围、压细炮管。SVG自动取非透明范围。裁切框只是像素区域，Sprite世界尺寸仍取既有模型。底盘/炮台旋转轴在各自中心，炮管延伸至既有muzzle_offset；全向轮的轮心、半径和方向取wheel_calibration，装甲外缘取已编译安装面。纹理不会改变碰撞体、质量、运动学或命中规则。

每个run重建实体节点，纹理跨run共享；同一对象跨渲染帧复用Sprite，只更新变换。只有获授权的位姿和对象进入渲染。没有合法自身位姿时隐藏车体，已消失对象及时释放。路径、目标估计环和局部雷达属于诊断图形，仍由授权数据绘制。

## 美术来源与维护

七张PNG由内置`image_gen`按用户确认的精细工业风生成，靶板经过一次4:3比例编辑；SVG是仓库内编写的简单图标。提示词组见 [PROMPTS](industrial/PROMPTS.md)。不使用运行时程序画坦克代替这些图片。

替换素材时保持正俯视、透明背景、旋转轴和部件方向；图片透明留白不代表世界尺寸。修改物理几何仍须走模型确认流程，不能为贴图调整课程参数。启动器从仓库目录加载资源；独立Godot导出/发行包必须另行随包携带这些资产，目前未验收独立导出。
