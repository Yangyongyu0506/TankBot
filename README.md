# TankBot

TankBot 是处于架构设计阶段的开源项目构想：将二维坦克对战、机器人算法学习、多文件 Python 编程与自主机器人竞技连接起来。

玩家逐步失去直接观察真实世界和手动控制的能力，通过自己的感知、定位、建图、规划与控制软件重新建立自主能力。项目当前**没有游戏实现、SDK、构建系统或可运行关卡**。

从 [技术文档索引](docs/README.md) 开始阅读；开发任务同时遵守 [贡献与 Agent 规则](AGENTS.md)。首个实现任务见 [开发路线图](docs/10_DEVELOPMENT_ROADMAP.md)。本轮产物是设计文档、JSON Schema 和接口样例，不代表相关功能已经实现。

目标平台为 Windows、Linux、macOS 和浏览器；每个平台必须通过验证后才列为受支持平台。建议核心采用 Rust，前端采用 TypeScript，具体技术组合仍为 Proposed。
