# 40 Navigation C4：连续路径追踪

## 目的、范围与确认

用户已确认本关目标、地图、接口数据、运动限制、检查点、追踪误差、时限和终局优先级。稳定ID为navigation.c4，前置navigation.c3，仍使用navigation独立工程。本机实现与验证接受于 [ADR-0052](adr/0052-generated-continuous-path-tracking.md)，证据见文末验收；本关不是路径规划教学，不增加物理/传感器模型。

复用C3的四模块闭环，只将位置控制模块替换为PathTrackingModule：玩家EKF候选→PathFollower→Twist参考→原WheelController→轮电压→权威物理。Odometry仍为对照。绘图来源继续为玩家估计，裁判真值不进入模块输入。

## 准备阶段与路径接口

正式引用maps/navigation_warehouse.yaml，不复制墙体。先按已解析地图、完整底盘和初态校验，再在可信准备阶段执行有界搜索；在创建物理世界/玩家Worker之前完成。重试复用同一ResolvedScene；浏览器加载已解析引用并复验，不因部署/短测重新采样。地图覆盖产生新引用，仍只计练习。

路径由独立seed流控制终点选择。Dijkstra搜索8邻接自由格，禁止斜穿封闭格角；随后可见性捷径、圆弧圆角、重采样，再逐线段验证。最终点、控制点和终点均由算法计算，不存在课程固定答案。网格、平滑参数和尝试/节点上限全部在关卡YAML。

默认搜索格0.20m，规划余量0.30m，交付安全余量0.15m；两者均在车体外接圆半径之上扩张障碍AABB。0.8×0.6m车体半径0.50m，故搜索/交付保守安全通道半径分别0.80/0.65m，覆盖任意yaw下完整圆角矩形。平滑半径1.0m、构造步长0.025m；最终局部半径至少0.70m、相邻转角≤0.35rad，显著高于0.5/1.5≈0.33m运动学极限，为固定提交延迟留出空间。保守通道会拒绝部分实际上可通过的狭窄间隙，这是本关的明确取舍。

最多20000网格节点/搜索展开、64终点尝试，平滑构造至多8192点，至多256交付点。最终长度12–18m、起终点距离≥5m、直接连线被障碍阻断，绕行增量≥0.6m、累计转弯≥1.2rad；不自交，所有线段和端点安全。不能满足时PATH_GENERATION_FAILED有界报错，绝不放松评分或输出穿墙路线。

生成用的稠密圆弧折线不是交付真相；重采样交付新的折线，其自身弧长每段0.10m，首尾保留且最后一段可更短。搜索栅格与输出采样间距互相独立。圆角和重采样后重新验证完整通道、长度、转弯、自交及终点距离。路径身份绑定地图、车体尺寸、初态、参数、seed和生成版本，另记录最终路径摘要。

路径可重复不等于任意部署时刻的得分完全相同：传感器沿用既有从run开始采样的独立随机流，准备阶段也会推进，编辑/短测所耗时刻会改变正式部署时看到的噪声样本。严格A/B闭环应重建相同ResolvedScene、固定正式部署/首控制tick，并记录传感器采样时刻、seed、代码revision、路径身份及构建环境；重部署本来就不重置正式任务或随机流。实际网页的人工作业时刻不同，应报告实际误差而不要求与受控测试逐位相同。

公开参考一次写入启动配置path_tracking_parameters，按permissions.data_access.task_inputs的path_reference授权；不在每批传输整个数组，不新增Topic中间件。适配器将points_m转换为不可重新打开写权限的float64 ndarray，shape=(N,2)。玩家API为：

```python
class PathFollower:
    def __init__(self, reference_speed_mps: float, max_vx_mps: float,
                 max_wz_radps: float, position_tolerance_m: float) -> None: ...

    def update(self, estimated_pose: NDArray[np.float64],
               path_xy: NDArray[np.float64], dt: float) -> Twist: ...
```

estimated_pose为只读map系(3,) [x,y,yaw]，path_xy[i]为map系[x,y]米制坐标，dt为算法执行间隔。没有真实位置、真实速度、路径最近点索引或World句柄。全路径静态参考与当前/历史测量严格区分；不强制Pure Pursuit、Stanley或其他控制律。

## 控制、时间与评分

参考速度0.4m/s，指令vx∈[0,0.5]m/s，wz∈[-1.5,1.5]rad/s，vy及非平面分量为零。允许减速、零速度和原地转向；负vx明确拒绝，不能绕过Authority校验。短暂实际后移不是倒车指令。Twist只进参考缓存和轮控制器，不调用速度伺服或修改真实位姿。

沿最终折线每1m自动生成顺序检查点，含起终点。真实质心进入半径0.50m即确认，每物理tick最多一个，无中途停稳要求。终点仍需距末点≤0.35m、真实平移速率≤0.05m/s、|wz|≤0.10rad/s连续0.5秒。

从首次正式轮控制提交生效开始，逐物理tick计算真实质心到完整折线所有线段的最短距离d，累计sum(d²·dt)/sum(dt)，不按离散采样点或当前检查点评分。RMSE≤0.20m、最大距离≤0.50m。重复tick不重复计分；测试和实验不计分，重试清空，重部署保留原计时/检查点/误差，终局冻结。

每固定子步检查Rapier既有求解器的active contact（包含既有预测接触约定），任一墙体接触锁存到该物理tick的私有观测；不新增碰撞参数，也不以包围盒近似接触或渲染效果评分。该观测只供裁判，不增加传感器或普通视图消息。

优先级为碰撞→控制故障→偏离>0.50m→全部检查点/终点停稳后的合格成功→已停稳但累计RMSE不合格→超时。终点停稳时立即结算，不能停留稀释误差；第120秒最后允许tick仍可成功。沿用60Hz/4子步、30Hz编码器、2Hz GPS、10Hz四模块和activation+6tick提交。模块声明总上限与后端整批墙钟现由 [41](41_RUNTIME_EXECUTION_PROFILES.md) 分开约束，默认值取可信目录并在尝试内冻结；不是每模块CPU配额，也不能延后提交门。

## 取舍、验收与开放项

保守外接圆比朝向相关搜索简单且安全；最短路裁判生成不属于玩家规划能力。完整路径走启动配置避免每批大消息，不提供新运行时服务。路径误差只在结束显示，避免隐含扩大真值反馈。

验收包括多seed生成/有界失败、平滑后复验、时间加权误差/检查点/终局边界、真值无旁路、参考限幅/缺测、测试隔离、重部署/重试、源码/进度兼容，以及原生/Pyodide真实编辑测试部署通关。[初次报告](reports/NAVIGATION_PATH_TRACKING_VALIDATION.md)保留当时20ms配置及失败；后续30/40ms实验性默认下的完整UI与候选对照见 [Runtime报告](reports/RUNTIME_EXECUTION_PROFILES_VALIDATION_20261107.md)。这些结果不代表其他平台或低于1%的整局截止失败率。
