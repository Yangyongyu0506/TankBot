# C4 中心自瞄课程验收

日期：2026-10-26。范围：用户撤销 C4 车头 GPS/中心 Radar 两点融合，改为复用 C3 观测和敌车模型的自动瞄准；C5 延续匿名装甲与全向小陀螺。设计见 [28](../28_WEAPONS_PROGRESSIVE_ESTIMATION.md)、[30](../30_ARMOR_OBSERVATIONS.md)、[ADR-0038](../adr/0038-center-target-auto-aim.md)。

## 配置与接口

- `levels/c0.yaml`–`c3.yaml` 不改。C4 与 C3 的地图、初态、目标动力学、传感器、随机流、双方 HP、整车扣血、规则、评价和 120 秒时限完全相同。
- C4 的 tracking 继续发布原 `target_polar_estimate@1`；aiming 消费该估计并输出既有角加速度/单发消息。键盘、手柄及程序旧速度接口不获武器控制权限，底盘仍禁用。
- 通用 PredictiveAimingModule 使用目标采样 tick 的公开自身位姿进行极坐标投影，有界历史长度取现有 YAML；无对应样本时按无目标输入处理。测试用移动后的自身位姿确认没有错误地套用最新坐标变换。
- C4 不生成、授权或可视化 GPS/装甲观测，不要求敌车 yaw。预测器收到空 `(0,3)` 装甲矩阵，C5 则收到四块真实公开安装几何；消息形状与 SDK 保持兼容。
- C4/C5 脚手架为 4.1.0；F2 三文件高亮、详细类型、中心/装甲预测差异和人工控制撤权均来自 YAML。旧融合器、滤波器、预测器、控制器和历史保留。

## 实际网页验证

使用独立临时 Workspace、settings、progress 和无头 Firefox，通过真实 CodeMirror 编辑、保存、测试得到 Ready、部署得到 Active，检查自动关闭编辑器及运行期锁定，依次完成 C3→C4→C5。C3 使用读取授权画面的人工 QA 操作器，C4/C5 无人工控制，均由玩家程序自主击杀。

原生网页三关已通过，C4 终局 RMSE 0.285 m，C5 为 0.026 m。证据为 `.m1-cache/c4-auto-aim/native-ui.json` 与对应 tree/running 截图。

浏览器 WASM/Pyodide 三关复验通过，证据为 `.m1-cache/c4-auto-aim/browser-ui.json` 和对应截图。C4/C5 均经真实 Test/Deploy 后由程序自主击杀，C5 另检查授权画面只有匿名装甲观测、没有中心 Radar/GPS。首次复验未启用 QA Worker 适配器，人工操作器误用了 HTTP 路径，C3 等待通关超时；已启用隔离测试配置的 probe_enabled 并增加工具前置校验，不调整生产物理/资源预算。

## 限制

普通玩家需要实现/适配自己的预测器；旧版要求非空 yaw/GPS 的算法不会自动改写。通关存档和稳定 ID 保持，既有通关不强制重置。多种随机种子、长时间学习效果、其他 OS/浏览器及 Arena 安全尚未在本轮验证。
