# ADR-0019 四轮 90° 旋转对称全向底盘修订

- Status: Accepted
- Date: 2026-10-22
- Scope: 全向轮组几何、轮速观测、里程计和显示；用户确认后实施
- Amends: 局部修订 ADR-0015/0018 的平行麦克纳姆轮约定；其余边界继续有效

## Context

用户明确纠正：全向底盘需要四组轮子绕车体中心以 90° 间隔旋转对称，而非此前平行安装的麦克纳姆小车。修订前 Core 编码器、仓库 Python 里程计和显示模型均使用旧布局，必须一起更改，不能只旋转轮子贴图。

用户随后回复“符合”，明确接受固定普通全向轮、对角 X 方位、R=0.25 m、r=0.10 m，保留车体碰撞外形及质量/受力伺服。此前 Proposed 安装方案据此转为 Accepted。

## Decision

采用四个固定普通全向轮，转轴沿中心径向、主滚动方向沿圆周切向，相邻轮组整体相差 90°。轮心角 α 从 base_link 的 +x 向 +y 计，轮心 p=R[cosα,sinα]。公开轮径与轮距是标定，不能由 Renderer 自行猜测。

已确认选择：

| 项目 | 已采用方案 | 替代 |
| --- | --- | --- |
| 轮型 | 固定普通全向轮，径向轮轴/切向主驱动 | 独立舵轮；或旋转安装的麦克纳姆轮，均需要不同运动学 |
| 方位 | 对角 X：45°/135°/225°/315° | 十字 +：0°/90°/180°/270°，或用户给定偏角 |
| 轮心半径 | X 方案 R=0.25 m | + 方案 R=0.22 m，或用户指定 |
| 延续参数 | 轮半径 r=0.10 m；现有 0.8×0.6 m 碰撞外形与质量/受力伺服 | 若用户要求改变外形/动力学，另确认 |

将唯一配置中的轮组安装参数同时用于 Core 和公开标定，Renderer 从同一参数派生轮心/安装角，不再独立维护四组显示坐标。SDK 输入仍为 JointState，Twist 的 vx/vy/wz 形状不变；具体几何版本须显式标记，不默默套用旧麦轮反解。

## Kinematic Interface

任一固定全向轮的理想滚动观测满足：

`r*qdot_i = t_i · ([vx,vy] + wz*[-p_iy,p_ix])`。

采用上述普通全向轮，选择正轮轴径向向内、正滚动方向为逆时针切向，则 `t_i=[-sinα_i,cosα_i]`，得到：

`qdot_i = (-sinα_i*vx + cosα_i*vy + R*wz)/r`。

四轮等角分布的反解为：

`vx = -(r/2)*Σ(sinα_i*qdot_i)`；`vy = (r/2)*Σ(cosα_i*qdot_i)`；`wz = r*Σ(qdot_i)/(4R)`。

轮角增量可用同一线性关系反解车体增量，再进行已有位姿积分。当前仅实现此普通全向轮模型；若未来引入舵轮或麦轮，必须另设模型版本，不能沿用这些约束。

参考 [ros2_control 官方全向轮运动学](https://control.ros.org/master/doc/ros2_controllers/doc/mobile_robot_kinematics.html)：轮速映射需由轮心分布、轮径和正轴约定共同确定。该文档使用相反的轮转正方向；这里显式声明向内轮轴，不能直接复制其符号。只参考接口/数学，不引入 ROS2/DDS 依赖。

## Alternatives / Consequences

仅改变渲染会使编码器与外观不符；仅改 Core 会使 Python 仍用旧标定；让 Renderer 自己存另一套安装位置会再次漂移。采用共同几何输入并明确模型版本，代价是旧轮组配置/示例需要显式迁移。玩家持久 Workspace 不自动覆盖；仓库参考示例随接口修订。

受限力/力矩伺服和理想滚动观测仍是现阶段聚合刚体模型。改变安装布局不等于已经模拟四个轮电机、摩擦锥或独立轮接触，这些不在本修订中暗中引入。

## Acceptance Criteria / Open Questions

用户确认完成；实现验证覆盖：相邻轮心/轮轴严格相差 90°；Core 与 Python 对纯 vx、纯 vy、纯 wz 及混合运动正反解一致；轮序改变不影响按名反解；30 Hz 编码器和 600 tick 闭环通过；差速/武器/权限不回归；真实浏览器显示四组旋转对称的轮子并继续保持世界朝向固定。实测与限制见 [全向轮验收报告](../reports/OMNI_VALIDATION.md)。

## Calibration / Compatibility

内部配置升级为 1.3，轮组标定为 `radial_omni@1`；wheel-calibration.schema.json 验结构，Host/Core 验四轮唯一、90° 等间隔及正半径。轮序仍为 front_left/front_right/rear_left/rear_right，方位分别 45°/315°/135°/225°，按名字连接而非猜测顺序。Core、仓库参考反解及 Renderer 使用相同配置；UI 不再保存独立轮心坐标或麦轮滚子角。

删除未发布的旧麦轮标定字段，不保留偷偷套用旧公式的兼容分支。旧配置须人工迁移，旧记录须匹配其原模型版本；不重写玩家 Workspace。公开 JointState/Twist 的单位、字段及权限不变，但轮转正方向以新的显式标定版本为准。
