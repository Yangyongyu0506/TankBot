# ADR-0034 授权的运行中教学评估

- Status: Accepted
- Date: 2026-10-26
- Scope: C2 累计位置 RMSE 的教学 UI；局部修订 ADR-0022

## Context

用户要求在 C2 代码运行期间直观看到 RMSE，以理解去噪效果。原有累计位置误差已按采样 tick 在 Authority 计算，但 ADR-0022 将其全部延至终局。直接给 Runtime 真值会破坏感知边界，按关卡 ID 打开显示则违背 YAML 插件设计。

## Decision

增加通用、默认不授权的 allowed_metrics 与 evaluation.live_feedback 声明，仅在 C2 配置累计位置 RMSE。管理 API 对 UI 返回获授权的标量和计数；不添加机器人 Topic，不传输真实位置、误差向量或逐样本误差。HUD 显示数值、有效样本数及有界走势，编辑器也显示同一数值。

公式和计分时序沿用原实现：位置 RMSE = sqrt(sum((x_est−x_true)^2+(y_est−y_true)^2)/N)，单位 m，真值与估计采样时刻对齐。只有正式部署的新、合法输出且有匹配历史的样本计入；测试不计入，重复/倒退采样不重复统计。重新部署不清零，重试建立新 run 清零；终局冻结并与最终报告一致。无有效数据时显示等待，不显示零误差。

## Alternatives

仅结束后反馈难以观察算法运行；用提交时的真值会混入控制链时延误差；仅给最近窗口会改变已有最终指标的含义。先保留本次尝试累计 RMSE，并明确跨部署累计；当前不增加新窗口指标、雷达基线分数或真值轨迹。

## Consequences

运行中聚合误差是 C2 明确授权的教学信息，玩家可据其反馈调试；不再对该关宣称完全没有评分 oracle。玩家 Python 的普通接口仍无此读取权限，其他关卡默认不授权。此授权不自动适用于 Arena。浏览器本地场景仍由设备所有者控制，权限是接口隔离。

## Acceptance

数值、采样时间、空数据、测试/重复部署/结束/重试及 Runtime 隔离测试通过；原生与 Pyodide 普通玩家 UI 已验证固定视口、曲线和编辑器显示，见 [验收报告](../reports/LIVE_RMSE_VALIDATION.md)。接受范围限于现有 C2 教学反馈和已验证的本机平台。
