# ADR-0036 独立底盘配置与统一碰撞/装甲安装

- Status: Accepted
- Date: 2026-10-26
- Scope: 局部修订 ADR-0015/0030/0033 的配置位置，以及全向车体几何

## Context

C5 的径向全向外观小于旧 0.8×0.6 m 统一车体，装甲显示浮空，教学参数与外观冲突。用户要求底盘独立配置，并明确确认 0.42×0.42 m、圆角 0.08 m、四面装甲 ±0.21 m、宽 0.24 m 和车头 GPS +0.21 m；质量、独立惯量、伺服、阻力保持。

## Decision

用 `config/chassis/*.yaml` 保存通用底盘类型、几何、装甲安装、GPS 与外观。`game.yaml` 显式列出模型资产，关卡只选择已注册模型和装甲启用。统一安全加载/校验并编译现有私有 DTO；Core 使用独立目标碰撞外形和同源装甲接触面，教学、SDK 配置、估计显示与开发者显示使用同一静态标定。协议消息和权限不扩宽。

允许外部引用的是通用引擎组件模型，不是关卡专属附加配置或可执行插件。稳定关卡 ID、源码和存档保持。应用配置升为 2.0，旧内联私有配置继续兼容。

## Alternatives

仅移动装甲线段会使首次接触和扣血仍在旧外形；放大车身可避免改物理，但用户选择紧凑尺寸；在 C5 分支写尺寸再次制造配置漂移。独立装甲碰撞体会改变已确认的质量/碰撞与弹丸语义，本轮不采用。

## Consequences

新增有界模型加载和 Schema，打包/夹具须包含模型；目标与玩家可采用不同形状，伺服仍使用自身质量/惯量。全向实例的碰撞范围和 GPS 杠杆臂明确改变，旧预测器必须读取运行时标定，不得写死原偏移。伸出轮组仍无独立碰撞体。

## Validation

用户确认是几何变更依据；技术验收见 [29](../29_CHASSIS_PROFILES.md) 及 [报告](../reports/CHASSIS_PROFILES_VALIDATION.md)，覆盖真实命中面、多源一致性、源码保留和两种 Runtime。接受范围不宣称所有平台或未来机器人模型已验证。
