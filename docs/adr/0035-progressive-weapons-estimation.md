# ADR-0035 Weapons 渐进估计与多文件自瞄

- Status: Accepted
- Date: 2026-10-26
- Scope: 用户确认的 C3 极坐标输出、C4 车头 GPS、C5 小陀螺与编辑文件树；局部替代 ADR-0032 的课程安排

## Context

原 C4 仅靠中心轨迹估计 yaw，原地转向存在方向盲区，首次装甲任务叠加过多负担。用户要求保留 C0–C2，依次引入原始极坐标滤波、不同安装点的观测融合、预测与自主武器控制，并明确 C3 输出仍为我方车体系 r/theta。

## Decision

采用用户逐项确认的 [28](../28_WEAPONS_PROGRESSIVE_ESTIMATION.md) 模型：C3/C4 人工武器，120/180 仿真秒；C4 前侧中央 GPS 10 Hz、独立 x/y 噪声 0.15 m、10% 丢失、12 m 截获且穿墙；C5 全向底盘沿原路径平移并以 3 rad/s 目标自转，程序角加速度/单发、180 秒，保留融合和装甲。控制、传感器、目标、几何和随机流参数在 YAML 中。

新增 `gps_fix@1` 与 `target_polar_estimate@1`，不改已有消息形状。C3 渲染/评分只以已公开自身位姿投影玩家极坐标估计。C5 预测与控制分别编辑 Python 文件，在同一模块内组合；Topic 层继续固定 tick 交换。F2 目录树高亮由关卡教材元数据声明。

后续 [ADR-0037](0037-anonymous-armor-observations.md) 局部替代 C5 的 GPS/中心 Radar 融合：该关只提供最近可见装甲的匿名极坐标，并采用四重对称朝向语义。C0–C4 与本 ADR 其余决策保持。

后续 [ADR-0038](0038-center-target-auto-aim.md) 局部替代 C4 的 GPS 融合/人工装甲任务：C4 沿用 C3 模型、中心观测与 120 秒整车击杀条件，改为程序自瞄；C5 在此基础上处理匿名装甲和小陀螺。GPS 协议与组件保留兼容，不再由正式关卡启用。

## Alternatives

删除装甲会失去几何/姿态的学习场景；直接提供真值 yaw 绕过观测估计。只调整噪声或时限无法补充方向信息。要求所有自瞄逻辑写在一个函数会妨碍已有滤波器复用。逐项新增关卡初始化函数违背纯 YAML 插件；因此新增可复用组件，关卡只配置组合。

## Consequences

保留旧 ID、进度、源码与已存 revision；新系统文件走预览升级，已有控制器保留旧接口兼容字段。新增 C5 与两个只读 SDK 类型需要同步 Schema、打包、说明和测试。公开带噪 GPS 是明确传感器授权，不是玩家读取 World；UI 可视化授权仍独立。

## Validation / Open Questions

接受依据为用户对任务顺序和新增模型的明确确认；实现证据见 [验收](../reports/WEAPONS_REDESIGN_VALIDATION.md)。测试覆盖技术可达性与边界，不宣称证明教学效果、多 seed 公平性或所有平台支持。GPS/Radar 当前同期、零延迟，异步融合留待未来。
