# ADR-0018 授权样本时间插值、平移跟随相机与独立外观

- Status: Accepted
- Date: 2026-10-22
- Scope: 浏览器显示时间、相机与两底盘外观；不改权威物理或协议语义

## Context

用户指出弹丸低帧率、需要世界朝向固定的平移跟随相机，并要求全向底盘使用独立的 RoboMaster 风格麦轮外观。检查发现物理与 RAF 已分开，但弹丸直接使用 10 Hz 快照位置，且车体插值按网络到达间隔重置，未统一处理真实采样时间。

## Decision

采用 [15](../15_RENDERING_DESIGN.md) 的 SceneTimeline：30 Hz 授权快照、独立 RAF、按样本仿真时间缓冲/lerp，保持帧/来源/权限边界，不外推未来或重算碰撞。位姿与累计炮台角尊重各自采样时刻。配置分别指定普通/估计显示时延与有界历史。

相机只取已显示车体的 x/y，世界方向固定；无估计时不读真值。模型配置拆为 tracked differential 与四轮 mecanum 两个完整条目，视觉不反写碰撞体。所有参数集中于同一配置文件，内部版本升为 1.2，已有协议 Schema 不变。

## Alternatives

更高快照率但无插值不能解决显示刷新率不同；前端预测弹道/碰撞会制造第二权威；跟随真实位置会绕过权限；共用车壳只改颜色不足以区分两种运动结构。采用单独显示时间层、固定朝向相机及独立部件配置。

## Consequences

增加有界缓存与可配置显示时延，需在接收抖动、失源和权限变化时清理。两快照间精确反弹拐点与极短生命周期仍受采样限制，不能用插值声称无误差物理回放。无需增加图像资产、第三方渲染库、ROS 依赖或修改 Core 动力学。

## Evidence / Acceptance Criteria

用户三项要求明确授权；JS 数值/生命周期/相机测试、Python 物理独立性回归与真实浏览器帧采集见 [报告](../reports/RENDERING_VALIDATION.md)。其他技术 ADR 的 Proposed 状态不因此改变。
