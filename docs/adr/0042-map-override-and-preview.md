# ADR-0042 启动地图覆盖与只读授权预览

- Status: Accepted
- Date: 2026-10-28

## Context

用户要求启动参数覆盖关卡绑定地图，并在游戏中提供预览和渲染；随后明确选择自定义地图仅作练习，不计正式通关。地图可以包含遮挡和初态冲突，不能仅替换显示而保持旧物理。

## Decision

以 --map 解析并冻结地图资产，将覆盖作为进程级配置贯穿重试和切关。沿用 scene.walls 物理/遮挡/显示路径，不修改协议或玩家源码。重叠初态拒绝启动，不默默移动机器人。尝试票据绑定自定义练习标记，权威端禁止其写入正式完成记录。

新增只读地图预览接口与模态 UI；开发者查看资产目录，玩家仅查看当前关卡明确允许的地图。预览不切换仿真、不暂停时限，输入与游戏控制隔离。

## Alternatives

只覆盖 UI 会使碰撞和地图不一致；每次重试重读关卡会丢失启动意图；自动移动初态会改变未确认的任务语义；全部地图公开会泄漏未来未知地图课程。运行中热切地图需要独立的生命周期设计，当前使用重启服务显式选择。

## Consequences

同一关卡可以用于不同布局练习，但地图改变后不能保证原巡逻或任务仍可完成。所有地图覆盖均不计正式成绩，原进度不丢失。保持仅通过现有 YAML 提供模型参数，未新增地图脚本或外部依赖。原生及浏览器共用配置和规则，授权范围保持独立。

## Validation

见 [31](../31_MAP_OVERRIDE_AND_PREVIEW.md)。覆盖 CLI、重试/切关、路径/初态拒绝、授权裁剪、原生和浏览器 HTTP 及练习进度；UI 使用真实 Firefox 检查布局、输入隔离和截图。接受范围不包含新导航课程。
