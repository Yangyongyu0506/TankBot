# ADR-0008 显式 Contract 与渐进式 SDK

- Status: Accepted
- Date: 2026-10-20
- Scope: Module API、交互和教学适配

## Context

初学者需要填函数，后期需要多文件自主软件；如果两阶段采用不同运行机制，前序代码难以延续。

## Decision

模块声明类型化输入/输出、生命周期、频率/触发、依赖、预算与状态版本。模块内部直接调用算法函数，模块间以 Topic 端口连接。函数包装、类和高级组装共享相同 Contract/Host 校验。首发同步回调，不以任意 async/线程行为定义仿真时间。

## Alternatives

单文件全逻辑简单但不利于复用；所有函数都通过消息调用过度复杂；无限制模块互调绕开调度和权限。混合方案保留两者适用范围。

## Consequences

增加元数据与连接检查，但可静态发现类型错误、替换系统模块和录制输入。跨模块有固定延迟；单 worker 是机器人内共同故障域。具体 SDK 签名仍须由实现验证，不等于已发布包。

## Validation / Open Questions

函数/类等价夹具、多文件导入、依赖环、缺输入、错误输出、重置、超时与手动 API 权限测试。异步后台计算在有必要的时刻单独 ADR，见 [05](../05_ROBOT_MODULE_SYSTEM.md)。
