# ADR-0038 C4 中心目标自瞄与渐进装甲课程

- Status: Accepted
- Date: 2026-10-26
- Scope: 局部替代 ADR-0035 的 C4 GPS 融合课程；保留 ADR-0037 的 C5 匿名装甲模型

## Context

用户明确撤销 C4 的车头 GPS/中心 Radar 两点观测，要求 C4 直接引入自动瞄准，敌车、观测与判定沿用 C3；C5 在自瞄基础上处理有效装甲和全向小陀螺。旧课程同时增加传感器融合、姿态、装甲和控制负担，复用路径不清楚。

## Decision

C4 与 C3 使用相同地图、初态、差速巡逻、中心 Radar、双方 3 HP、整车受击扣血、120 秒和终局优先级；底盘仍禁用。仅武器控制转为玩家程序的角加速度与单发接口，不授权人工武器或旧速度接口。保留 C3 的 PolarTracker 输入输出，增加独立 TargetPredictor 与 AutoAim 文件。

通用 PredictiveAimingModule 接受合同声明的极坐标目标或地图系目标位姿。极坐标按相同采样 tick 的公开自身位姿投影，不查询 Ground Truth；有界位姿历史长度来自 YAML。C4 无敌车 yaw、无装甲安装数组；预测器先预测中心。C5 保留匿名装甲传感器、模 90° 相位、有效装甲与小陀螺，复用控制器并扩展预测器。

C4/C5 管理脚手架升至 4.1.0；更新经过预览确认，已有滤波器、融合器、预测器、控制器与历史不覆盖。ID、进度和既有消息形状保持。GPS 的通用组件及协议兼容类型保留，但当前正式关卡不启用或授权 GPS。

## Alternatives

继续保留 GPS 融合违背本轮课程要求；给 C4 默认自瞄答案会跳过控制练习；把预测与控制写为专属关卡逻辑破坏 YAML 插件边界。将极坐标估计用最新自身位姿投影会在后坐/反作用运动时产生时序错误，故按采样 tick 匹配。

## Consequences

C3 的算法可直接沿用，C4 引入武器闭环，C5 聚焦新的观测几何与旋转预测。旧预测器若要求非空 yaw/装甲，需要玩家自行适配；框架不得替换其源码。跨模块仍有固定提交延迟，需在教学中说明并测试。

## Validation

接受依据为用户明确修改要求；实现、权限、无损迁移和实际部署证据见 [验收报告](../reports/CENTER_AUTO_AIM_VALIDATION.md)。多 seed 难度、教学效果和其他平台仍未验证。
