# ADR-0041 共享地图资产与教学空旷场地

- Status: Accepted
- Date: 2026-10-28
- Scope: 地图配置来源及当前教学场地；不改变物理模型或课程接口

## Context

六个关卡重复保存相同墙体，自由试验场也内联同一地图。用户要求提取公共资产、为 Hello Robot / Weapons 使用空旷场地，并准备不同尺寸和内部布局的导航地图。

## Decision

复用既有 `world.map.source: asset`，C0–C5 共同引用 `assets/maps/open_training.yaml`。保留 12×8 m 边界及全部初态、巡逻和任务，只移除原内部隔墙。空旷仍有边界墙，避免暗中改变反弹/自伤规则。

原地图独立为 training_legacy，默认自由试验场通过 scene.map 引用；加载器解析后仍生成原 scene.walls，兼容旧内联配置，拒绝同时指定两者。增加大型空旷、错列隔墙、仓储通道资产，不新增关卡或导航功能。资产格式沿用墙体列表，不加入新的地图系统。

## Alternatives

继续内联会造成重复与漂移；无边界场地会扩大现有规则变化；立即引入栅格或多边形地图不符合当前实现需要。用全部关卡改地图尺寸会改变射击距离/巡逻与教学负担，因此当前只移除内部墙，新尺寸用于独立资产。

## Consequences

模型、接口、权限、玩家源码/存档不变；穿越旧内部墙位置的射线、车辆和弹丸将不再被阻挡。共用资产修改影响所有引用方，打包必须保留资产目录。未来导航关卡必须配置不与障碍重叠的初态，不默认沿用原点。

## Validation

[地图目录及编写指南](../../assets/maps/README.md) 提供布局预览与验证命令。自动测试验证全部资产、通道连通、路径/尺寸错误、真实碰撞边界及旧场景兼容；历史关卡基线只允许明确移除内部墙。未来导航课程、任意地图编辑器和跨平台导航验证不在本次完成范围内。
