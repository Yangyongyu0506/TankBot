# ADR-0011 限定确定性与分层回放

- Status: Accepted
- Date: 2026-10-20
- Scope: 可复现范围、记录与调试

## Context

教学与比赛需要重测算法和审计，但 Python 截止、浮点、物理库和编译目标会破坏无条件重现承诺。

## Decision

明确 D0 逻辑顺序、D1 同构建物理重放、D2 受控算法重跑和 D3 跨平台容差比较。记录实际接受控制、传感器采样/交付、输出、超时、版本/构建和策略切换。私有审计与授权公开 Replay 分开。seek 换 run 并清历史；初期从初态重算，不假设物理快照可完整恢复。

## Alternatives

只记随机种子不足以重现异步截止；只记画面不能调算法；承诺所有硬件位级一致缺乏证据；直接公开完整录制会泄漏秘密信息。

## Consequences

记录量与保留成本更高，但可区分算法差异和执行环境差异。录制传感器离线比较不等于闭环对比，后者需各自重新生成传感器输入。

## Validation / Open Questions

固定构建 600 tick 与更长回归；输入重放、分叉闭环、篡改块、权限和 seek 测试。快照恢复、压缩和保留期后续决定，见 [07](../07_SIMULATION_DESIGN.md)。
