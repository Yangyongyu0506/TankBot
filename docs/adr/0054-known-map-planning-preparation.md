# ADR-0054 已知地图、一次性规划准备与静态路径交付

- Status: Accepted
- Date: 2026-11-10
- Scope: navigation.c5及复用的规划准备任务；不改变旧课程、物理或周期profile

## Context

用户已逐项确认Navigation C5：玩家实现膨胀、搜索和后处理，复用C4跟踪链。搜索不能占用周期30/40ms往返，也不能复用测试Worker结果作为正式授权。原始地图、规范膨胀、任务选择、路径校验和UI必须共用坐标/安全定义。

## Decision

可信准备阶段从同一地图解析覆盖边界和0.20m原始bool网格，按模型外接圆及0.15m安全余量确定4格方形膨胀。裁判仅选择满足约束的终点，不把参考搜索结果提供给玩家。冻结任务身份绑定地图、模型、参数与seed。

为候选Runtime增加显式准备阶段：解释器/项目测试初始化完成但不构造规划器或周期模块；收到绑定run/deployment/task的规划请求后，才导入玩家规划器、构造并调用plan，完整往返由外部Supervisor执行独立5秒截止。清理测试导入缓存；规划结束清理项目模块缓存。Authority独立验证结果，再将只读静态路径交给该候选的周期模块初始化。setup/reset不调用规划器，不能通过它们提交替代路径。测试与正式部署使用各自全新的Worker，均重新规划一次。

准备任务有独立输入/输出、预算、错误与关闭合同，不是周期Module或可任意调用的服务。及时结果也须通过身份和完整路径校验；旧Worker/迟到响应拒绝。5秒预算不扩大周期声明额度或墙钟，也不移动activation+6tick门。

路径由2–512行float64坐标构成，严格检查首尾、间距、全部节点与线段。规范膨胀只为裁判/UI计算，程序输入仍是原始网格；不自动修补、平滑或重采样。行驶只考察无碰撞到达停稳，追踪误差/实际路程仅终局诊断，无C4检查点或误差门槛。

## Alternatives

周期update搜索破坏控制截止；setup内规划混淆解释器启动与规划预算；复用测试结果丢失正式身份/预算；预先膨胀或给参考路线取消学习目标；按关卡ID分支破坏插件边界，均不采用。

## Consequences

新增准备协议、OccupancyGrid、任务/路径验证和独立裁判；原Transport保留安全差异。共享Worker不提供逐模块CPU硬隔离，5秒是墙钟。正式空模板没有搜索解；旧算法与历史保留，系统文件升级继续预览/CAS。具体合同见 [42](../42_NAVIGATION_GLOBAL_PLANNING.md)。

## Acceptance Evidence

用户确认了模型、接口和阈值。2026-11-11 的本机验收覆盖 A*、Dijkstra、seed 0/1/2、超时与非法路径、旧工程保留，以及原生和 Firefox/Pyodide 的编辑、测试、部署、通关与重试往返。运行配置的 experimental 状态和适用范围见 [验收报告](../reports/NAVIGATION_GLOBAL_PLANNING_VALIDATION.md)。
