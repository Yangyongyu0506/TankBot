## 已确认的方程

车体局部速度为 `(vx, vy, wz)`，指令为 `(vx_cmd, vy_cmd, wz_cmd)`：

```text
Fx_servo = clamp(m * (vx_cmd - vx) / tau_x, -Fx_max, Fx_max)
Fy_servo = clamp(m * (vy_cmd - vy) / tau_y, -Fy_max, Fy_max)  # 仅全向
Fy_servo = 0                                             # 差速
Mz_servo = clamp(I * (wz_cmd - wz) / tau_w, -Mz_max, Mz_max)

Fx_drag = -cx * vx
Fy_drag = -cy * vy
Mz_drag = -cw * wz
```

各项力与力矩由物理世界叠加；碰撞或将来的后坐力不能被直接设速度抹掉。在无阻力、未饱和、无坐标旋转耦合时，单轴响应为 `G(s)=1/(tau*s+1)`；实际有阻力时允许稳态误差。该近似不是独立轮电机或详细履带接触模型。

## 实施门与验收

协议验证、Python SDK、Runtime 边界、授权视图与构建探针可以先行。任何物理分支只在对应选择与参数确认后实现；用户答复不明确时继续询问，不能以超时或预选项代替确认。每次答复在此记录，并同步对应规范、配置、测试和 ADR。模型与尚未实现的武器能力不能混写为已完成 M1 功能。

第三轮追加要求：所有控制和模型的可调参数统一放入 `config/m1.json`，禁止在程序中硬编码或用隐藏默认值补缺；数学常数、协议定义与数值运算本身不属于可调模型参数。场景从同一文件选择差速/全向配置，不能在其他实现文件再保留另一组参数。

理想编码器由真实车体运动反算轮速并积分轮角，墙体阻停后不模拟电机空转，差速横滑不被左右轮编码器观测。IMU 不用车体系速度的简单差分代替世界加速度变换；不得另加物理库隐式阻尼。

## 轮组与 IMU 接口

四轮顺序固定为 `front_left, front_right, rear_left, rear_right`；车体系 x 前、y 左、正 yaw 逆时针，`k = half_length + half_width`：

```text
omega_FL = (vx - vy - k*wz)/r
omega_FR = (vx + vy + k*wz)/r
omega_RL = (vx + vy - k*wz)/r
omega_RR = (vx - vy + k*wz)/r
omega_L = (vx - track*wz/2)/r
omega_R = (vx + track*wz/2)/r
```

每子步对实际轮速作梯形积分获得累计轮角；当前为理想运动观测模型，不假设有未实现的轮电机。所有底盘发布 `/robot/sensors/joint_states` / `joint_state@1`，单位 rad/rad·s⁻¹；旧 `encoder@1` 左右累计距离接口保持不变。IMU 将每子步真实世界速度差按区间中间姿态转换，再累加到 30 Hz 窗口；角速度为各子步前后真实 wz 的梯形积分除以窗口时间，避免将接触位置纠正误认为陀螺测量。接触冲量包含在加速度观测中，tick 0 无前一窗口时输出零加速度。

## 尚未执行的武器状态方程

令车体世界角为 theta，炮台相对角为 q，绝对角 phi=theta+q：

```text
T = clamp(I_t*(u-q_dot)/tau_t, -T_max, T_max) - c_t*q_dot
I_t*phi_ddot = T + external_torque_turret
q_ddot = phi_ddot - theta_ddot
body receives -T through the joint
v_bullet = v_muzzle_world + v_rel * direction(phi)
J_recoil = -m_bullet * v_rel * direction(phi)
```

上述转动式适用于中心轴/质心配置；未来若移动安装点，必须由完整双刚体关节求解平移/转动耦合，不沿用中心轴简式。冲量作用于炮口并通过关节传递，不把线速度或角速度直接重设。弹丸继承炮口速度时，共同平移部分按用户最后确认的固定质量近似处理：弹丸质量不从车体中扣除，后坐仅与相对发射动量对应，是已约定的游戏近似而非声称含弹药总系统严格守恒；已接受此游戏近似；若改为有限弹药质量，必须重新交互确认，不能静默改变质量模型。

轮组实现从配置中的滚子角计算 `c=cot(beta)`、`k=half_width+half_length*c`，以 `c*vy` 代替上面 45° 特例的 vy；SDK 使用相同公开标定的逆矩阵。这样 45° 的参数数值仍只来自配置，程序不藏第二份几何值；本轮验证/确认仅覆盖 X45，改变滚子角仍需新验证。

P20 弹药质量记账：Confirmed，用户最后答复“采用”。弹药不从车体扣重，车体质量/惯量保持不变；后坐为已约定的相对发射动量冲量。配置 `deferred_weapons.mass_accounting=fixed_chassis_mass`，不把无限弹药质量来源近似说成完整系统严格守恒。该部分只定模型，尚无武器代码。
